# kingpost-website

طراحی تأییدشده وب‌سایت kingpost.ir (نسخه بازطراحی کامل — آبان ۱۴۰۵).

- `index.html` — صفحه اصلی + فروشگاه + آموزش (تک‌فایل، راست‌به‌چپ، فونت وزیرمتن)
- `assets/` — عکس محصولات فروشگاه و تصاویر خانواده

نکته استقرار: این ریپو فقط قالب‌های فرانت‌اند است. مسیرهای بک‌اند (`/shop`، `/admin`، API پست) روی سرور می‌مانند و دست نخورده‌اند. برای به‌روزرسانی خودکار سایت از این ریپو، سرور باید با webhook یا pull خودکار به آن وصل شود.
